# 功能地图（v0.1.0 · 开发中）

> 本文件是「砚田现在能做什么」的完整清单，按工作流分区。末尾对比了与线上闭源产品的差异和后续路线；架构实现见 [architecture.md](./architecture.md)，版本计划见 [roadmap.md](./roadmap.md)。

## 一页总览

| 分区 | 你在哪里用 | 解决什么问题 |
| --- | --- | --- |
| 写作 | `/editor/[novelId]` | 三栏工作台：左栏四页签（目录 / 章纲 / 设定 / 档案）+ Tiptap 正文 + AI 助手，自动保存与字数统计 |
| 大纲 | 写作台左栏「章纲」页签（旧 `/novel/[novelId]/outline` 自动跳转） | 总纲 / 卷纲 / 章纲三级大纲，浮窗里就地编辑，可从章纲生成正文 |
| 设定 | 写作台左栏「设定」页签（旧 `/novel/[novelId]/bible` 自动跳转） | 角色卡、世界观设定卡；按 AI 可见性与揭示章节筛选上下文 |
| 档案 | 写作台左栏「档案」页签（旧 `/novel/[novelId]/archives` 自动跳转） | 每章故事档案：摘要、角色状态、资源总账、时间线、伏笔，供后续章节回溯；可一键补建 |
| AI | 编辑器右栏 / 正文快捷条 | 3 个内置智能体 + 自定义人设；统一 Agent 对话，正文和资料候选经审阅后写入 |
| 设置 | `/settings`（或左下角齿轮打开的悬浮窗） | 模型服务、统一默认模型、提示词预设、编辑器、外观、数据导入导出 |
| 数据 | 设置页 / 文件系统 | 单文件 SQLite、Markdown/TXT 导出、TXT 导入拆章、重新生成示例作品 |

## 写作

**三栏工作台**（左：作品目录树；中：正文；右：AI 助手，可折叠）

- 卷/章树形目录：新建、重命名（双击或「⋯」菜单）、拖动排序（卷与章，章节可拖进别的卷）、状态标记（草稿/修改中/定稿）。章纲页签里的分卷列表同样可以拖动、重命名和删除。
- 写作台左栏四页签：目录 · 章纲 · 设定 · 档案，页签会保活、切换不丢滚动与编辑状态；章纲、设定、档案都在浮窗里就地编辑，不离开正文。
- `Ctrl / ⌘ K` 快速跳转：搜索章节、角色、设定、档案，或直接切换左栏页签；`Ctrl / ⌘ + Shift + 1–4` 直达四个页签；`Alt + J` 聚焦右侧 AI；旧的大纲 / 设定 / 档案页面会自动跳回写作台。
- Tiptap 富文本正文：标题、引用、列表、加粗/斜体、分隔线；配 `.prose-paper` 排版（宋体、1.95 行高、段首缩进 2em）。
- 自动保存：停止输入 `autoSaveDelayMs`（默认 1200ms）后保存，`Ctrl/Cmd + S` 立即保存；顶栏显示「保存中 / 已保存 / 保存失败」。
- 实时字数：中文按字、英文按词（`countWords`），底栏显示本章字数、全书进度与每日目标。
- 专注模式与打字机模式：隐藏侧栏、光标居中滚动；字号、行高、正文字体可在设置里调。
- 沉浸模式：顶栏的放大按钮进入。进入后右上角有缩小按钮，右下角也能退出；`Esc` 同样有效。
- 选区即上下文：启用上下文中的「选区」后，选中的文字可随请求发送并作为改写对象；关闭时不会发送。

**AI 插入与改稿**

- 正文类 AI 产出（续写/扩写/润色/改写/去 AI 味/仿写）以**建议**形式返回，不直接写进正文。
- 根据任务生成续写、整章或选区修改候选；应用前显示目标和改动范围。
- 正文审阅：用户可逐处「保留」或「还原」，也可批量操作；未保留的部分不会写入正文（底层 diff 见 `lib/diff/blocks.ts`）。

## 大纲

**三级大纲，逐级下钻**

| 层级 | 内容 | 入口 |
| --- | --- | --- |
| 总纲 | 一句话前提、主题、基调、主线、支线、角色弧、世界规则、结局、钩子 | 章纲页签「总纲」 |
| 卷纲（每卷） | 卷摘要、卷弧目标、关键事件、伏笔计划 | 章纲页签按卷切换 |
| 章纲（每章） | 目标、视角、冲突、情绪曲线、场景列表、情节节点、结尾钩子、目标字数 | 章纲页签（可定位到当前章） |

- 可以直接编辑，也可以让 AI「生成总纲 / 卷纲 / 章纲」，产出落到对应编辑区。
- 章纲与章节绑定，写作时 AI 上下文默认包含当前章纲。
- 总纲/卷纲/章纲都会参与上下文装配，可在 AI 的上下文预览里查看「AI 现在能看到的大纲」。

## 设定

**角色卡**

- 字段：姓名、别名、角色定位（主角/反派/配角/导师/群像/其他）、性别、年龄、身份、外貌、性格、目标、秘密、弧光、说话风格、关系网、当前状态、标签。
- 关系网：角色之间可互指（关系 + 备注），用于一致性检查。
- **AI 可见性**：`aiVisible` 开关（默认开）决定这张卡是否可供 AI 读取；关闭时 `@` 引用也不能绕过。`revealAtChapter` 填写后，在当前章节到达该章前默认隐藏；没有当前章节时也默认隐藏。作者本轮明确 `@` 引用可例外提供未揭示的卡，但不应提前在正文点破。
- 「揭示章节」留空 = 不按章节隐藏；填章节号会在到达之前默认隐藏卡片，而不只是提醒 AI。

**世界观设定卡**

- 分类：力量体系、地理、势力、物品、规则、历史、自定义；支持父子层级与排序、pin 置顶。
- 同样具备 AI 可见性（`aiVisible`）与揭示章节筛选（`revealAtChapter`）。

**伏笔卡（悬念）**

- 状态流转：已埋设 → 推进中 → 已回收 / 已放弃；记录埋设章节、回收计划、关联角色。
- 写作时把「待回收伏笔」带给 AI，并在上下文预览里单独列出。

**资料卡辅助生成**

- 可在对话中要求助手根据正文和已有资料补全角色或设定；候选按字段展示，确认后才写入。
- 资料浮窗的「AI 助手」会引用当前卡片并附带未保存草稿，填入对话但不自动发送；新建卡片以草稿形式附带。

## 档案

**每章一份故事档案**，用于解决长篇里「AI 记不住前文」的问题：

| 区块 | 内容 |
| --- | --- |
| 本章摘要 | 200 字以内的情节摘要 |
| 角色状态 | 每个出场角色的位置、状态、关系变化 |
| 设定状态 | 本章新出现或被改写的世界规则/物品状态 |
| 资源总账 | 灵石/钱财/寿命等数值的增减与结余（`ledger`） |
| 时间线 | 本章发生的关键事件顺序 |
| 伏笔 | 埋设/推进/回收情况 |
| 冲突 | 本章遗留的矛盾与待解决问题 |

- 由「提取故事档案」基于正文生成，你也可以手改。
- 「一键补建全书档案」只处理**已经写了正文、还没有档案**的章节，按顺序逐章提取。已有档案的章和空章都会跳过；没有缺口时会马上结束，不再请求模型，也不改正文。按钮旁的说明可以悬停查看。
- 正文变化后档案标记为 `stale`（已过期），提示重新提取；`pending` 表示待确认。
- 重新提取人工校订过的档案时保留人工内容，补充新事实；模型识别到正文冲突时会提示确认。人工档案正确就同步修改正文，正文正确就手动修正档案；只改正文不会自动覆盖人工档案，冲突识别也不能保证无遗漏。
- 开启档案时，默认按 `archiveDepth` 取当前章**之前**最近 N 章档案，避免提前泄露；明确 `@` 引用可例外读取指定档案，关闭档案开关时不能读取。

## AI

### 3 个内置智能体 + 自定义

| 智能体 | 角色 | 擅长 |
| --- | --- | --- |
| 主编（supervisor） | 通用助手 | 续写正文、改设定卡、理章纲、查档案 |
| 写作（writer） | 正文创作 | 续写、扩写、润色、改写，保持叙述视角与文风 |
| 设定（setting） | 资料补全 | 角色卡、力量体系、势力关系、设定树 |
| 自定义（custom） | 你定义的编辑 | 名称、职责、人设、额外要求由你在「设置 · 智能体」里配置 |

- 旧的内置智能体 id（策划 / 档案 / 审稿 / 考据 / 结构）已合并进主编，旧 id 会自动回落到主编，历史会话不会丢。
- 每个智能体的名称、职责、人设与额外要求都可在「设置 · 智能体」里改；对话中可随时切换智能体。

### 对话与技能

- 统一输入框处理讨论、起草与资料修改；「技能」在输入框内展开清单，选中即填好提示词，不自动发送。
- `Enter` 发送、`Shift + Enter` 换行；`@` 引用章节、角色、设定、伏笔或档案，引用列表打开时先选择条目。
- 技能面板内置 4 个常用技能（开书（融合仿写）/ 续写并同步 / 去 AI 味 / 章节诊断），点一下填好提示词、确认后发送。传统单点任务另有预设；内置预设只读，可新建自定义预设。

### 19 个单点 AI 任务

| 类别 | 任务 |
| --- | --- |
| 正文 | AI 续写、扩写、润色、改写、去 AI 味、爆款仿写 |
| 大纲 | 生成总纲、卷纲、章纲 |
| 资料 | 角色卡补全、设定卡补全 |
| 档案 | 提取故事档案、本章摘要 |
| 诊断 | 章节体检、一致性检查、节奏分析 |
| 其他 | 起名、写简介、自定义任务 |

正文快捷任务进入统一 Agent 流程：按需读取资料、生成候选，经正文或字段审阅后才写入。传统单点任务仍有各自的提示词预设。

### 上下文控制

- 「上下文」面板可配置总纲、卷纲、章纲、前 N 章摘要、故事档案深度、角色详略、世界观、伏笔、文风约束、选区和自定义指令。
- 抽屉展示作品资料及分节标题的 token 估算，不含系统提示、历史、当前提问及额外任务材料。它不是 Agent 实际输入的逐字清单；Agent 按任务需要调用工具读取。
- **上下文预算**默认 12000 token；普通装配超限时从低优先级分节开始，能逐条精简的先省略较早或排序靠后的资料，不足时丢弃该分节；仍超限再截断剩余内容。Agent 的规划、写作和资料整理分别检查任务材料，超限可能直接提示缩小范围或提高预算。`0` 只关闭应用侧预算限制：模型窗口已知时仍会检查完整请求，未知时无法硬性检查。
- **单次输出上限**为 0 时通常采用服务商默认值，Anthropic 兜底 4096，并非无限。
- 用量与费用区分输入、缓存命中输入和输出；接口未返回时按配置单价估算或显示未知，实际账单以服务商为准。详见 [Agent 工作流](./agent-workflow.md)。
- `@` 可指定本轮所需资料；角色与设定的 AI 隐藏开关仍然生效。

### 提示词白盒

- 内置任务预设可查看但只读；可新建自定义预设，配置 system prompt、user template、温度及任务类型（通用任务 / 长文任务）。
- 传统单点任务使用对应提示词模板；统一 Agent 使用自身规划流程和可配置的人设，见 [Agent 工作流](./agent-workflow.md)。
- 模板占位符（`{{novelTitle}}`、`{{context}}`、`{{selection}}`、`{{chapter}}`、`{{message}}` 等）由服务端在装配后替换。
- 自定义预设可编辑、启用/停用或删除；内置预设不能在设置界面直接修改。

### 模型与路由

- 11 个服务商快捷预设：设置页选品牌 → 填 Key → 主动拉取或手动添加模型 → 测试连接（OpenAI / DeepSeek / 通义千问 / Moonshot / 智谱 / Claude / Gemini / OpenRouter / 硅基流动 / Ollama / 自定义兼容）。
- 五类连接：OpenAI 兼容、Anthropic、Gemini、Ollama（本地）、离线演示模式。
- 对话与写作共用一个默认模型，可在设置悬浮窗或 AI 面板切换。
- 按 API Key 从服务商拉取模型列表（OpenAI 兼容 / Anthropic / Gemini / Ollama），也可以手动添加模型 ID；品牌快捷预设只填协议和地址，不内置推荐模型。
- 环境变量自动建 Provider：`*_API_KEY` / `OLLAMA_BASE_URL` / `YANFIELD_OPENAI_COMPAT_*` 首启自动创建，已有同名跳过、不覆盖手改配置。
- 「测试连接」显示耗时与返回片段；密钥在列表中掩码显示（`sk-****abcd`）；模型列表显示上下文窗口，方便设置上下文预算。

| 分组 | 内容 |
| --- | --- |
| 模型服务 | 快速添加 11 个服务商预设、增删改 Provider、拉取或手动添加模型、测试连接、设置统一默认模型 |
| 提示词 | 查看内置预设，增删改及启停自定义预设 |
| 外观 | 宣纸（浅）/ 夜航（深）主题，强调色为浅蓝；正文字号、行高、正文字体、段首缩进 |

| AI 与上下文 | 上下文开关与预算、用量统计、输入/输出单价（用于估算费用） |
| 数据 | 数据库路径与体积、导出（Markdown/TXT）、导入 TXT、重新生成示例作品 |

## 数据

- **存储**：`data/yanfield.db`（可用 `YANFIELD_DB_PATH` 改位置），WAL 模式；备份就是复制这一个文件（连同 `-wal` / `-shm` 一起复制，或先停服）。
- **导出**：按章 / 按卷 / 按全书导出 Markdown 或 TXT。
- **导入**：上传 TXT，可用正则识别章节标题，预览拆章结果后批量导入为卷章。
- **封面**：书架和作品概览用渐变底色。在「编辑信息」或新建作品里可选预置色，也可以自定义起始色和结束色。
- **示例作品**：首次启动在没有作品时生成《潮信》（2 卷 5 章 + 角色/设定/伏笔/档案/大纲）与离线演示模型。设置 → 数据里的「重新生成示例作品」只新增一部；`pnpm db:seed` 会删除作者为「砚田示例」或标题为《潮信》《长夜行》的所有作品，以及内置提示词预设，**同名自建作品也会被删除**，内置预设中的改动可能丢失。运行前停服并备份；重启时只有数据库没有任何作品才自动创建示例。
- **迁移**：schema 由 `lib/db/index.ts` 的 `CREATE TABLE IF NOT EXISTS` 管理，目前不做跨版本自动迁移；升级大版本前请先备份。

## v0.1.0（开发中，未发布）与线上产品的差异

| 维度 | 线上产品（闭源 SaaS） | 砚田 v0.1.0 |
| --- | --- | --- |
| 部署 | 云端账号 + 订阅 | 本机单进程，免登录，无遥测 |
| 数据 | 平台数据库 | 你电脑上的一个 SQLite 文件，可备份可迁移 |
| 模型 | 平台代理与额度 | 自填 baseUrl/key，任意 OpenAI 兼容服务、Anthropic、Gemini、Ollama |
| 上下文 | 「已为你智能装配」（黑盒） | 装配维度与预算可调，预览是估算，Agent 按需读取 |
| 提示词 | 固定 | 内置任务预设可查看，自定义预设与智能体人设可编辑 |
| AI 改稿 | 直接插入正文 | 强制 diff 逐块审批 |
| 协作 | 多人在线 | 单人本地（导出/分享文件代替） |
| 知识图谱/RAG | 有 | **无**，用「资料卡 + 故事档案 + 摘要近邻」替代 |
| AI 配图 | 有 | **无**，计划 v0.3 |
| 移动端 | App/小程序 | 无；桌面浏览器 + 响应式布局 |
| 运营内容 | 榜单、案例库、订阅 | 全部不做 |
