# 功能地图（v0.1.0 · 开发中）

> 本文件是「砚田现在能做什么」的完整清单，按工作流分区。末尾对比了与线上闭源产品的差异和后续路线；架构实现见 [architecture.md](./architecture.md)，版本计划见 [roadmap.md](./roadmap.md)。

## 一页总览

| 分区 | 你在哪里用 | 解决什么问题 |
| --- | --- | --- |
| 写作 | `/editor/[novelId]` | 三栏工作台：目录树 + Tiptap 正文 + AI 助手，自动保存与字数统计 |
| 大纲 | `/novel/[novelId]/outline` | 总纲 / 卷纲 / 章纲三级大纲，可从章纲生成正文 |
| 设定 | `/novel/[novelId]/bible` | 角色卡、世界观设定卡，控制「AI 能不能看到」以及在第几章才解锁 |
| 档案 | `/novel/[novelId]/archives` | 每章故事档案：摘要、角色状态、资源总账、时间线、伏笔，供后续章节回溯 |
| AI | 编辑器右栏 / 全局弹层 | 8 位智能体对话 + 19 个单点任务（续写、润色、去 AI 味…），全部流式 |
| 设置 | `/settings`（或左下角齿轮打开的悬浮窗） | 模型服务、单一默认模型、提示词预设、编辑器、外观、数据导入导出 |
| 数据 | 设置页 / 文件系统 | 单文件 SQLite、Markdown/TXT 导出、TXT 导入拆章、重新生成示例作品 |

## 写作

**三栏工作台**（左：作品目录树；中：正文；右：AI 助手，可折叠）

- 卷/章树形目录：新建、重命名（双击或「⋯」菜单）、拖动排序（卷与章，章节可拖进别的卷）、状态标记（草稿/修改中/定稿）。大纲页的分卷列表同样可以拖动、重命名和删除。
- Tiptap 富文本正文：标题、引用、列表、加粗/斜体、分隔线；配 `.prose-paper` 排版（宋体、1.95 行高、段首缩进 2em）。
- 自动保存：停止输入 `autoSaveDelayMs`（默认 1200ms）后保存，`Ctrl/Cmd + S` 立即保存；顶栏显示「保存中 / 已保存 / 保存失败」。
- 实时字数：中文按字、英文按词（`countWords`），底栏显示本章字数、全书进度与每日目标。
- 专注模式与打字机模式：隐藏侧栏、光标居中滚动；字号、行高、正文字体可在设置里调。
- 沉浸模式：顶栏的放大按钮进入。进入后右上角有缩小按钮，右下角也能退出；`Esc` 同样有效。
- 选区即上下文：选中一段文字后唤起 AI，选区自动进入上下文并作为改写对象。

**AI 插入与改稿**

- 正文类 AI 产出（续写/扩写/润色/改写/去 AI 味/仿写）以**建议**形式返回，不直接写进正文。
- 插入位置可选：光标处插入 / 追加到章末 / 替换选区 / 替换整章。
- 段落级 Diff 审阅：用户逐块勾选「采用」，未勾选的保持原样（实现见 `lib/diff/blocks.ts`）。

## 大纲

**三级大纲，逐级下钻**

| 层级 | 内容 | 入口 |
| --- | --- | --- |
| 总纲 | 一句话前提、主题、基调、主线、支线、角色弧、世界规则、结局、钩子 | 大纲页「总纲」 |
| 卷纲（每卷） | 卷摘要、卷弧目标、关键事件、伏笔计划 | 大纲页按卷切换 |
| 章纲（每章） | 目标、视角、冲突、情绪曲线、场景列表、情节节点、结尾钩子、目标字数 | 大纲页或写作页右侧「章纲」 |

- 可以直接编辑，也可以让 AI「生成总纲 / 卷纲 / 章纲」，产出落到对应编辑区。
- 章纲与章节绑定，写作时 AI 上下文默认包含当前章纲。
- 总纲/卷纲/章纲都会参与上下文装配，可在大纲页一键查看「AI 现在能看到的大纲」。

## 设定

**角色卡**

- 字段：姓名、别名、角色定位（主角/反派/配角/导师/群像/其他）、性别、年龄、身份、外貌、性格、目标、秘密、弧光、说话风格、关系网、当前状态、标签。
- 关系网：角色之间可互指（关系 + 备注），用于一致性检查。
- **AI 可见性**：`aiVisible` 开关 + `revealAtChapter`（第几章才允许 AI 知道）。未解锁的设定不会进上下文，避免 AI 提前泄底。

**世界观设定卡**

- 分类：力量体系、地理、势力、物品、规则、历史、自定义；支持父子层级与排序、pin 置顶。
- 同样具备 AI 可见性与揭示章节控制。

**伏笔卡（悬念）**

- 状态流转：已埋设 → 推进中 → 已回收 / 已放弃；记录埋设章节、回收计划、关联角色。
- 写作时把「待回收伏笔」带给 AI，并在上下文预览里单独列出。

**资料卡辅助生成**

- 「角色卡补全 / 设定卡补全」：从当前正文与已有资料推断缺失字段，产出以 diff 形式让你逐项采纳。

## 档案

**每章一份故事档案**，用于解决长篇里「AI 记不住前文」的问题：

| 区块 | 内容 |
| --- | --- |
| 本章摘要 | 200 字以内的情节摘要 |
| 角色状态 | 每个出场角色的位置、状态、关系变化 |
| 设定状态 | 本章新出现或被改写的世界规则/物品状态 |
| 资源总账 | 灵石/钱财/寿命等数值的增减与结余（`ledger`） |
| 时间线 | 本章发生的关键事件顺序 |
| 伏笔 | 埋设/推进/回收情况 |
| 冲突 | 本章遗留的矛盾与待解决问题 |

- 由「提取故事档案」基于正文生成，你也可以手改。
- 「一键补建全书档案」只处理**已经写了正文、还没有档案**的章节，按顺序逐章提取。已有档案的章和空章都会跳过；没有缺口时会马上结束，不再请求模型，也不改正文。按钮旁的说明可以悬停查看。
- 正文变化后档案标记为 `stale`（已过期），提示重新提取；`pending` 表示待确认。
- 上下文装配器会按 `archiveDepth` 取最近 N 章档案，让续写接得上前文。

## AI

### 8 位智能体 + 自定义

| 智能体 | 角色 | 擅长 |
| --- | --- | --- |
| 主编（supervisor） | 统筹与拍板 | 拆任务、给方案、协调其他智能体 |
| 策划（blueprint） | 大纲与结构 | 卷章节奏、爽点布局、钩子设计 |
| 写作（writer） | 正文生产 | 承接续写、场景展开、对话 |
| 档案（archivist） | 一致性档案 | 提取档案、追踪角色与资源状态 |
| 审稿（critic） | 批评与体检 | 找问题、给修改建议 |
| 设定（setting） | 设定补全 | 力量体系、势力、物品 |
| 考据（consistency） | 一致性核对 | 时间线、称谓、数值冲突 |
| 结构（structure） | 宏观结构 | 三幕/多卷结构、章节功能诊断 |
| 自定义（custom） | 你定义的编辑 | 名称、人设、技能由你配置 |

每个智能体带 3 个快捷指令（quick actions），点一下即发。

### 19 个单点 AI 任务

| 类别 | 任务 |
| --- | --- |
| 正文 | AI 续写、扩写、润色、改写、去 AI 味、爆款仿写 |
| 大纲 | 生成总纲、卷纲、章纲 |
| 资料 | 角色卡补全、设定卡补全 |
| 档案 | 提取故事档案、本章摘要 |
| 诊断 | 章节体检、一致性检查、节奏分析 |
| 其他 | 起名、写简介、自定义任务 |

所有任务共用一条链路：**上下文装配（可见、可预算）→ 提示词模板 → Provider → SSE → Diff 审阅 → 落库**。

### 上下文控制

- 每次对话/任务前可在「上下文」面板勾选：总纲、卷纲、章纲、前 N 章摘要、故事档案（深度）、角色卡（详略）、世界观、伏笔、文风约束、选区、自定义指令。
- 实时显示每个维度的 token 估算与总预算；**上下文预算**默认 12000 token（面板里可调，填 0 = 不限），超限按优先级自动裁剪并标注被丢掉的维度。
- 用量：设置里的「用量与费用」显示今日和累计的输入 / 输出 token 与请求次数。填上单价（元 / 百万 tokens）后给出估算金额，两项都留 0 则只统计 token。对话、写作任务和「AI 帮我写」结束时也会显示本次用量。服务商返回了 usage 时用真实数字，否则用本地估算。账单以服务商为准。
- 支持 `@` 提及角色/设定，把指定条目临时塞进上下文。

### 提示词白盒

- 19 个内置预设全部可见可改：system prompt、user template、温度、任务类型（通用任务 / 长文任务）。
- 模板占位符（`{{novelTitle}}`、`{{context}}`、`{{selection}}`、`{{chapter}}`、`{{message}}` 等）由服务端在装配后替换。
- 可另存自定义预设、按功能启用/停用；改坏了能一键恢复内置默认。

### 模型与路由

- 11 家主流服务商预设：设置页「快速添加」选品牌 → 粘 Key → 测试连接，一步接入（OpenAI / DeepSeek / 通义千问 / Moonshot / 智谱 / Claude / Gemini / OpenRouter / 硅基流动 / Ollama / 自定义兼容）。
- 五类连接：OpenAI 兼容、Anthropic、Gemini、Ollama（本地）、离线演示模式。
- 单一默认模型：对话与所有写作任务都用同一个模型，可在设置悬浮窗或 AI 面板随时切换；不强制区分对话 / 正文模型。
- 按 API Key 从服务商拉取真实模型列表（OpenAI 兼容 / Anthropic / Gemini / Ollama），也可以手动添加任意模型 id；预设模型仅作推荐兜底。
- 环境变量自动建 Provider：`*_API_KEY` / `OLLAMA_BASE_URL` / `YANTIAN_OPENAI_COMPAT_*` 首启自动创建，已有同名跳过、不覆盖手改配置。
- 「测试连接」显示耗时与返回片段；密钥在列表中掩码显示（`sk-****abcd`）；模型列表显示上下文窗口，方便设置上下文预算。

| 模型服务 | 快速添加 11 家主流服务商、增删改 Provider、按 API Key 拉取真实模型列表 / 手动添加模型 id、测试连接、设置单一默认模型 |

## 数据

- **存储**：`data/yantian.db`（可用 `YANTIAN_DB_PATH` 改位置），WAL 模式；备份就是复制这一个文件（连同 `-wal` / `-shm` 一起复制，或先停服）。
- **导出**：按章 / 按卷 / 按全书导出 Markdown 或 TXT。
- **导入**：上传 TXT，可用正则识别章节标题，预览拆章结果后批量导入为卷章。
- **封面**：书架和作品概览用渐变底色。在「编辑信息」或新建作品里可选预置色，也可以自定义起始色和结束色。
- **示例作品**：首次启动自动生成《潮信》（2 卷 5 章 + 角色/设定/伏笔/档案/大纲）与离线演示模型。设置 → 数据里的「重新生成示例作品」只**新增**一部示例作品，不删已有内容；命令行 `pnpm db:seed` 则相反——删除示例作品与内置预设、保留你自建的数据，重启后自动重建。
- **迁移**：schema 由 `lib/db/index.ts` 的 `CREATE TABLE IF NOT EXISTS` 管理，目前不做跨版本自动迁移；升级大版本前请先备份。

## v0.1.0（开发中，未发布）与线上产品的差异

| 维度 | 线上产品（闭源 SaaS） | 砚田 v0.1.0 |
| --- | --- | --- |
| 部署 | 云端账号 + 订阅 | 本机单进程，免登录，无遥测 |
| 数据 | 平台数据库 | 你电脑上的一个 SQLite 文件，可备份可迁移 |
| 模型 | 平台代理与额度 | 自填 baseUrl/key，任意 OpenAI 兼容服务、Anthropic、Gemini、Ollama |
| 上下文 | 「已为你智能装配」（黑盒） | 装配维度、token 预算、实际文本全部可见可调 |
| 提示词 | 固定 | 全部可见可改，可自定义预设 |
| AI 改稿 | 直接插入正文 | 强制 diff 逐块审批 |
| 协作 | 多人在线 | 单人本地（导出/分享文件代替） |
| 知识图谱/RAG | 有 | **无**，用「资料卡 + 故事档案 + 摘要近邻」替代 |
| AI 配图 | 有 | **无**，计划 v0.3 |
| 移动端 | App/小程序 | 无；桌面浏览器 + 响应式布局 |
| 运营内容 | 榜单、案例库、订阅 | 全部不做 |
