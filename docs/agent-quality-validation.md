# Agent 回复质量验证（2026-11-03）

在独立 QA 数据库中使用真实 DeepSeek API，所有书稿、人物与设定均为合成材料，没有修改用户作品。多轮累计记录 221 次底层请求，其中包含本地代理触发的限额失败；这不是 221 个独立用户任务。先执行两轮十项任务，再执行完整十四项场景，最后定向复测五项与三项。不能把工具协议成功率等同于内容正确率。

## 覆盖场景

- 只分析冲突、不修改；未知年龄外貌保留未知。
- 整理已有设定，不新增出航限制，同时保留旧卡的潮汐规则。
- 正文润色禁止新增资料，以及下一轮继续遵守限制。
- 短选区改写、追加约百字、同一轮修订追加内容、续写下一章。
- 只修改角色口吻；可见资料列表排除隐藏资料。
- Markdown 表格、中文引号、A & B 换行显示。
- 应用角色候选后继续修改，随后撤回；正文生成后基于证据提取资料。
- 轻量思考模式下多步读取、修改候选、完成答复。

## 发现与修正

初轮即使工具正常返回，也出现了删除作者已有规则、把“账本下”改成“账本里”、默认补充未知身份、字数不足却要求用户再确认原目标、说明与实际候选不一致等问题。因此逐条检查了模型最终说明和候选字段，并调整事实边界与回执提示。

代码修复包括：短选区不再默认按整章生成；无效选区在付费调用前拒绝；同轮追加修订替换新增部分；候选读取重算字数；新章缺标题时生成章节编号；资料整理禁令跨轮继承；资料工具返回实际字段前后预览和可能遗漏的原句。执行过程与总结复用安全 Markdown 渲染。

完整十四项一轮中，十三项通过脚本检查；下一章标题仍为泛称，随后补了服务端编号兜底。定向复测仍发现一次旧规则丢失，随后增加候选字段回执，最后两次同场景实测均保留了原规则。轻量思考多工具调用也正常完成。

## 仍需人工审阅

这些测试不证明模型永远不会虚构。曾出现未授权病史、重复晚饭时间线和轻微身份推断。提示词已约束这些情况，但“可能遗漏”检测只是原句匹配，无法证明语义等价；最终候选仍需作者逐项预览确认。字数与文风也不是每次生成都能完全满足。
