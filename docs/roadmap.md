# 路线图 Roadmap

> 版本目标来自 [v01-scope.md](./recon/v01-scope.md) 的范围取舍：先把「一个人独自写完一卷」做扎实，再向平台化扩。当前仓库版本为 **0.1.0（开发中，未发布）**：v0.1.0 区段列出的能力都已在代码里落地，但首个正式版本尚未发布。勾选状态以仓库实际代码为准，规划项可能调整，欢迎在 Issue 里讨论优先级。

## v0.1.0 — 能独自写完一卷（当前版本 · 开发中，未发布）

**目标**：本地一条命令启动，不接任何外部服务也能完整走完「构思 → 大纲 → 写作 → AI 改稿 → 归档 → 导出」的闭环。

- [x] 作品 / 卷 / 章三级结构，书架与作品概览
- [x] 三栏写作工作台：目录树 + Tiptap 正文 + AI 助手
- [x] 自动保存（停止输入 / `Ctrl+S`）、实时字数、专注与打字机模式
- [x] 三级大纲：总纲 / 卷纲 / 章纲
- [x] 资料卡：角色、世界观设定、伏笔；AI 可见性与揭示标注
- [x] 故事档案：摘要、角色状态、资源总账、时间线、伏笔、冲突；一键补建只处理已有正文且尚未建档的章节
- [x] 用量：记录输入/输出 token（优先用服务商返回值），设置里可填单价做费用估算
- [x] 3 个内置智能体（主编 / 写作 / 设定）+ 自定义人设；19 个单点 AI 任务
- [x] 上下文装配面板（维度、上下文预算、裁剪提示）
- [x] 逐块 diff 审阅后落库；AI 产出不直改正文
- [x] 五类 Provider：OpenAI 兼容 / Anthropic / Gemini / Ollama / 离线演示
- [x] 对话 / 写作双模型可分别配置，提示词预设可见可改；按 API Key 拉取真实模型列表
- [x] 设置页「快速添加」11 家主流服务商预设（baseURL、协议、推荐模型与上下文窗口已填好）
- [x] 环境变量首次启动自动创建 Provider（已有同名跳过；默认模型还指向演示模式时自动切到真实服务）
- [x] 上下文预算 `contextBudget`（默认 12000，`0` = 不限）与「单次输出上限」`maxTokens` 拆分
- [x] Provider 适配强化：中文错误提示、3 分钟超时、推理模型参数省略、reasoning 流式展示
- [x] TXT 导入拆章、Markdown/TXT 导出
- [x] 宣纸 / 夜航双主题、设置页、AI 调用日志
- [x] 写作台响应式与深色主题打磨、上下文抽屉预算可视化
- [x] 单元与协议测试（Vitest）、CI、Docker 单镜像部署
- [x] 部署材料：`.env.example`、`docker-compose.yml`、systemd 单元、反向代理与 HTTPS 文档、11 张产品截图

## v0.2 — 版本、导出与协作（规划中，未发布）

**主题**：让稿子可回溯、可带走、可交给别人审。

- [ ] **章节版本快照与回滚**：每章保留最近 N 个版本，可对比、可回滚；支持从某一版分叉出不同走向的草稿，对比后再合并
- [ ] **EPUB 导出**：在 Markdown / TXT 之外，按卷章结构生成 EPUB（封面、目录、元数据），可直接分发给读者或用阅读器校对
- [ ] **自定义 Agent 与插件机制**：在现有「自定义智能体」基础上开放更多可配置项（提示词、模型、可用工具）；插件负责自定义 AI 任务与导出格式
- [ ] **多人协作审校**：导出带批注的稿件，他人异步审阅后把批注导回（不做实时协同编辑，避免引入账号与实时基础设施）

## v0.3 — 从「单点 AI」到「工作流」（规划中，未发布）

**主题**：让资料之间连起来，让 AI 学会「像这本书」。

- [ ] **知识图谱**：角色/设定/伏笔/事件之间的有向关系图，支持在图谱上点选条目加入上下文
- [ ] **RAG 检索**：长作品按向量/关键词检索相关段落，替代朴素的「前 N 章摘要」
- [ ] **爆款仿写工作台**：拆解范文的结构/节奏/句式，产出可复用的写作模板（仅分析结构，不复制内容）
- [ ] **AI 配图**：角色立绘、场景插画、封面生成（接 OpenAI Images / 本地 SD 等），图片随作品归档
- [ ] 章节诊断增强：节奏曲线可视化、重复用词统计、场景目标达成度

## v0.4 — 编排与批处理（规划中，未发布）

**主题**：把重复劳动交给任务队列，作者只做决策。

- [ ] **任务中心**：多章批量续写/润色/体检，带进度、可暂停、可取消
- [ ] 多智能体编排：主编拆解任务 → 写作/审稿/考据串行或并行执行，产出汇总报告
- [ ] 去 AI 味批量处理与风格一致性检查（跨章）
- [ ] 预设市场：导入/导出提示词预设与智能体配置（纯 JSON，本地文件交换）
- [ ] 预设与作品包分享：把提示词预设、智能体配置、整本书导出成可交换的文件包（不是实时协作）
- [ ] 文档区：作品级设定文档、素材库、灵感便签

## v1.0 — 稳定与可扩展（规划中，未发布）

**主题**：可以长期托付书稿的版本。

- [ ] 数据库 schema 版本号与自动迁移（升级不丢稿）
- [ ] 插件/扩展机制：自定义 AI 任务、自定义导出格式
- [ ] 多语言界面（zh-CN 起步，en 其次）
- [ ] 性能：十万字级作品的加载与 diff 优化、虚拟滚动
- [ ] 完整用户文档 + 视频教程 + 示例项目库
- [ ] 发布制品：单文件二进制（可选的 Tauri 桌面壳）、Docker 镜像、一键脚本

## 明确不做

- 订阅、积分、付费墙等商业化机制
- 账号体系、云同步、平台托管数据
- 抓取他人作品用于仿写/洗稿
- 公共案例库、榜单、社区运营
- 多人实时协作编辑（异步审校见 v0.2，导出/分享文件即可满足当前场景）
