# 行为准则 Code of Conduct

## 我们的承诺

砚田是一个面向写作者的开放项目。我们承诺：无论年龄、体型、可见或不可见的残障、族裔、性别认同与表达、经验水平、教育程度、国籍、外貌、种族、宗教、性取向，参与者都能获得无骚扰的协作体验。

## 我们希望的行为

- **对事不对人**：批评代码、文档、设计，不攻击人。
- **给上下文**：报告问题时说明环境（系统、Node 版本、模型服务）、复现步骤、期望与实际结果。
- **尊重作者**：讨论写作技巧时保持善意；不评判他人作品的内容题材。
- **小步快跑**：PR 尽量小、可读、可回滚。
- **承认不知道**：不确定的事说「我不确定」，比硬编一个答案更有价值。

## 不可接受的行为

- 人身攻击、侮辱、嘲讽、贬低性言论；任何形式的歧视与骚扰。
- 发布他人的隐私信息（住址、真实姓名、API Key、未公开稿件）——**绝对不要**把你或他人的 `data/yanfield.db`、密钥、未公开书稿贴到 Issue/PR 里。
- 抄袭、洗稿、内容农场式使用：本项目面向原创写作，不欢迎用砚田批量生成低质内容或抓取他人作品仿写。
- 在讨论区发布广告、拉群、引流、加密货币/博彩等内容。
- 其他在专业协作环境中明显不当的行为。

## 适用范围

适用于所有项目空间：Issue、PR、评审意见、文档、提交信息，以及以项目名义参与的外部场合（如社区群、线下活动）。

## 执行

如果你遭遇或目睹了不当行为，请通过以下方式联系维护者：

- 在相关 Issue/PR 中 @ 维护者，请求私下沟通；
- 或发送邮件至维护者在仓库主页公开的联系邮箱。

维护者会尽快、公正地处理，并**对举报人信息保密**。处理措施包括但不限于：提醒、删除内容、要求公开道歉、临时或永久禁止参与项目。恶意举报同样会被处理。

## 归属

本准则参考 Contributor Covenant 2.1 的精神编写，并结合本项目「写作社区」的场景做了增补。
